## Projects

### [paperpack](https://github.com/ChangkeunJ/paperpack) &nbsp;·&nbsp; [live](https://paperpack-7v7.pages.dev/)

Australian working holiday tax and departing superannuation, worked out in the browser.

Every regulatory figure carries the ATO page it came from and the date it was last
checked, and a CI gate refuses any number that arrives without its source. Nothing the
user types ever leaves the page — no backend, no analytics, no network calls at all.
Eight languages, zero dependencies.

`TypeScript` `Zero-dependency` `Cloudflare Pages` `i18n ×8`
